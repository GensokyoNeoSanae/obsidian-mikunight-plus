# tools

## `presets-hsl.mjs`

八套配色预设的体检表。纯 Node，不依赖任何包，也不读写文件。

```powershell
node tools/presets-hsl.mjs
```

输出四段：

1. 每套 HSL 对应的真实 hex，以及它对背景色、对正文色的对比度；
2. 一段可以直接粘回 `main.js` 的 `PRESETS` 结构；
3. 相邻两套之间的色相差、饱和度差、明暗差，按「三条同时成立才算重复」的判据标出撞色；
4. 明暗接近的成对提示（色相差够大就不算问题）。

判据是三条同时成立才算重复：**色相差 < 25° 且饱和度差 < 25 点 且 明暗对比 < 1.3**。色相撞但饱和度、明暗拉得开的，观感就是两回事 —— 比如浅粉和玫红。

各套的饱和度与明度是逐套定的，不是笔误，别去「统一」它：同一个 HSL 明度在不同色相上的感知亮度差很多（相对亮度权重 R 0.2126 / G 0.7152 / B 0.0722），青绿要压低亮度、品红要抬高，八块才看着一样亮。

**改完预设记得同步这张表**，否则它检查的是旧数据：表里的顺序和数值都跟着 `main.js` 的 `PRESETS` 走，方便两边逐行对照。
